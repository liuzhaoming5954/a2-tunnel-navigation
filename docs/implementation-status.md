## 新机接入和实机录包

- 新机维护电脑 PC4 已部署固定版本的项目源码并完成传输校验和 Python 回归。PC2 已核对原厂感知服务、前雷达与配套 IMU 数据，并部署独立采集工具。整套 ARM64 ROS 2 和 SDK 构建、安装及运行仍待验证。
- 现场使用原厂遥控完成静止、分段往返和完整环线采集。首次整圈录包缺少返回停稳窗口，随后延长录制时限并加入停稳标记与尾段补录。
- 第二次整圈录制约 **8 分 32 秒**，取得 **5,120 帧点云、102,340 条 IMU**。维护 Wi-Fi 断开期间持续机载记录，返回联网后按停稳标记补录约 10.9 秒并完成校验回传。除首帧外，点云扫描时段均有完整 IMU 覆盖。

## 离线建图和闭环结果

在本机使用 DLIO 生成同步点云与位姿，再由 RTAB-Map 保存地图。返回长通道的纵向修正已接入主配准和备用配准。针对历史两轮 **0.75 米** 的回放差异，修正 IMU 缓冲区读写、自适应统计并发和子地图构建时序，并按扫描时间有序回放。

| 指标 | 最新结果 |
| --- | --- |
| 回放重复性 | 427 秒前缀和整圈回放的 4,270 帧共同输入、4,118 对同步位姿与 167 次子地图目标切换一致。 |
| 返回长通道 | 第 370–389 秒两轮均估计前进 4.964 米。第 370–377 秒两轮均为 0.856 米，回放差异为零。该短段的原始雷达估计提示可能少计，现场距离待核验。 |
| 整圈跟踪 | 整圈有序回放发布 4,964 对同步点云与位姿，未发生失锁。 |
| 闭环复核 | 原自动候选的时序复核未通过，改用未入图的原始扫描交叉验证同一重访区域，保留原有门槛。闭环后首末关键帧水平距离由 **10.19 米降至 12.8 厘米**。 |
| 直通道形状 | 第三段直通道轨迹横向拟合误差，闭环前为 2.5 厘米，仅闭合首尾后为 14.1 厘米，加入沿途约束后为 6.9 厘米。 |

闭环首尾距离反映地图内部的一致性。全图尺度、通道宽度和拐角位置需结合独立测量或验证数据核验。新闭环地图已完成起点、第二个拐角和返程相似直通道三组离线冷启动。起点和拐角通过多帧与留出扫描核对，三维位置与地图参考的最大差异分别为 3.15 厘米和 4.73 厘米。相似直通道的六个窗口均保持未定位。三组未观察到错误锁定，结果仍需通过独立采集和实机验证。

原始录包、地图副本、按时间戳的复测报告和几何审计保存在本机受控试验目录。离线建图补丁与诊断工具仍处于本机试验阶段，正式 `a2_localization` 包和可上机发布组合待集成。[建图工具和依赖基线](mapping-readiness.md)

## 地图目标点验证

从闭环候选数据库的 357 个关键帧导出 0.20 米分辨率的二维栅格。使用本轮离线净空参数，在同一通道的两个录包位置间规划出约 1.75 米路径。原停稳起点因净空不足被拒绝，未知目标和不连通区段也被拒绝。ROS 2 只读探针已通过合成地图与里程计的正常、缺 TF 和过期用例。当前证据支持本机地图点选和静态规划。现场尺度、外廓、在线定位、指令桥接、控制权和停车仍待验证。[目标点验证流程](a2-goal-validation.md)

## 下一轮验证

1. 固定闭环候选地图版本，补做独立录包重定位和现场尺度核验。明确相似直通道冷启动的恢复条件，检查误匹配、拒绝及重新定位前的状态。
2. 核实新 A2 的目标构建依赖、SDK 状态与控制权证据。按现场用例完成原厂独立停车和接收端失联停车记录。
3. 在地图与定位检查通过、停车证据齐备且运动链路完成后，安排受控低速巡航。新增载荷安装后进入各自接入与离线业务联调。
