# 代码实现进度

2026-11-05。任务、存储、公共接口、平台和 bringup 包为 `in_progress`，其余 7 个包仍为 `planned`。用户已确认原装雷达、IMU 和摄像头可用，新增巡检载荷尚未安装。目前无法连接 A2、没有实机录包；继续推进独立的本机建图准备，DLIO 固定版本候选已在 Jazzy/x86_64 构建成功。实机输入适配、完整建图和 A2/Humble 验证仍待，M0 未完成。

| 当前实现 | 验证范围 |
|---|---|
| 任务准备、一次性准入、单调时钟有效期 | 拒绝无凭据/过期启动；等待 journal 锁后重新采样时间；同请求重复不重新执行 |
| 自检、定位、巡检、暂停/恢复、故障清除、取消 | 不能跳阶段；故障不能靠普通暂停解锁；未确认停稳不报告取消完成 |
| controller 重建与身份隔离 | 同 boot 的进程重建清旧凭据，保留完成点位；旧 controller 的新命令被拒；历史收据与当前状态分别返回 |
| SQLite journal | 快照历史、收据与有序事件事务提交；冲突检测；跨连接并发去重；提交故障/进程退出恢复 |
| 本机合成演示 | 临时 SQLite，模拟检查和停稳观测；重建后重发旧 Start 不恢复巡检；现场确认后新授权才能继续 |

首批核心验证：20 个任务核心测试、16 个 journal 测试通过，合成演示通过；两个 ament_python 包在本机 Jazzy/x86_64 的 colcon 构建通过。后续任务/存储/平台及 mock 增量共 75 项测试通过，采集工具另有 21 项测试，分别见下文。GitHub 公共仓库已创建，远端 CI 结果以 [Actions](https://github.com/liuzhaoming5954/a2-tunnel-navigation/actions) 为准。

运行命令见[根 README](../README.md)。CI 按同样的 unittest 命令运行核心测试与合成演示。库兼容 Python 3.10+；当前本机执行使用 Python 3.12，Humble/Python 3.10 与 A2 ARM64 组合仍待验证。

任务/存储增量仍是纯业务库与存储库，ament_python 包元数据用于工作区集成。目前已提供 mock-only 任务 ROS 服务与启动组合，仍无真实运动授权。

`bundle_verified`、自检/定位状态、本地确认与停稳标志必须由未来可信适配器提供。本轮不提供包签名验证、身份认证或真实传感器检查，不能把调用者传入 `True` 当作实机保障。未来的停车/撤权快速通道先执行，再更新任务状态；SQLite 锁等待不能阻塞该通道。

当前 journal 保存所有快照与事件，尚无保留期、容量水位、媒体提交和同步确认实现；长时间实机运行前必须补齐。记录点位完成只是内部业务事件，未实现照片/气体验收。返桩、对准、低电策略、健康监控、进程监督及控制时序亦待后续增量。

测试使用真实临时 SQLite、并发连接和提交边界的子进程退出。此证据不等同于 A2 存储介质断电或底盘失联停车；后者继续按[设计方案](design/A2-PRO_Utility_Tunnel_Navigation_v0.5.md) M0–M4 验证。

## 不依赖硬件的任务 ROS 与组合启动增量

这一增量提供不连接硬件的软件演示与回归。此前将“新增巡检载荷未安装”误写为所有传感器未安装，现已更正：原装雷达、IMU 和摄像头可用，优先开展真实录包与建图验证；新增载荷后移，正式 M0–M4 准入条件保留。

- 新增 `MissionCommand` / `GetMissionState` 和 `mission_node`，只支持 mock profile；公开状态明确模拟、不具备运动能力，授权凭据仅直接响应。
- mock 适配仅接受登记的合成方案和点位，自动模拟自检/定位/停稳；服务器健康观察与稳定请求身份分离，重试保留历史结果。
- mock 平台样本需持续推进，重复/倒序样本不能续期，旧 source session 不能覆盖新 session。监控使用 steady clock，运行中断流触发锁存。
- 新增 `a2_bringup` mock launch，固定无 SDK 的两个节点，任一进程退出关闭整组；SQLite 持久进度，节点重建清旧凭据，core/mock 任务模式隔离。
- 当前 Python 测试：任务核心及适配 38 项、journal 16 项、bringup 配置 7 项；加上平台 14 项 C++ 测试，共 75 项。
- 五包本机 Jazzy/x86_64 构建通过。任务 ROS smoke 通过 26 次命令，验证完整生命周期、历史收据、公共观察无凭据、重启故障暂停/保留点位、重新确认授权及模拟平台断流保护。
- CI 配置已加入任务 ROS 集成与 bringup 配置检查；源码仓库采用公共可见性，执行结果见 Actions。

演示见[模拟任务指南](mock-mission.md)。真实传感器、身份认证、定位、控制权、停车及实际运动尚未接入自研软件，模拟布尔结果不能作为实机放行证据。
