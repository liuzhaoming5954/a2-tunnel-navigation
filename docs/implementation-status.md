### PC2 单点导航开发机验证

2026-11-21，在开发机 ROS 2 Jazzy 回环环境先从源码启动上位机和 PC2 网关，再从分别解压的两个交付包启动同样的服务。两轮各提交一个 `map` 目标（X = 1.125 米，Y = 0.625 米，航向 = 0.6 弧度）。合成 `NavigateToPose` 服务收到对应坐标和航向四元数，回传剩余距离 0.625 米及 `succeeded`。同一目标 ID 重试后，每轮动作端均只收到一个目标。另一次 ROS 回环测试按 ID 取消在途目标并收到 `canceled`。

两轮网关测试使用合成 TF 和里程计。ODIN1 机身位姿桥在独立测试中完成含旋转和平移外参的换算，并在导航域发布同一时刻的 TF 和里程计。发布候选通过 65 项测试（网关 35 项、导航 17 项、观测与位姿桥及启动和打包脚本 13 项），无跳过。Vue 生产构建通过。重新打包后，上位机包的 14 项与 PC2 包的 23 项文件校验全部通过。使用解压后的包加载网页脚本和样式，再次复测目标状态、距离反馈、成功终态和同 ID 重试，动作端共收到一个目标。[开发机回环复测](development.md#33-巡检与单点导航的开发机复测)

下一轮在 PC2 部署 Humble Nav2，静止核对 BIN 与导航栅格的配准、实测安装外参、障碍输入和候选速度。底盘控制与停车验证通过后，再记录实际到点误差与停稳。两点连续巡检目前只在模拟器完成。[部署与验收](pc2-single-goal.md)

### PC2 独立遥控停车

11 月 21 日，0.05 米/秒的前进请求触发平面速度保护。11 月 22 日，A2 站稳后按 A，PC2 发出停车指令，底盘返回成功，模拟自主进程退出。随后档 0 下的两轮 1 秒试验分别请求 0.02 和 0.03 米/秒，现场均未见迈步，发令程序因超时主动停车并退出。

同日将前进请求设为 0.10 米/秒、最长 5 秒，现场确认迈步。本轮由速度保护触发停车，PC2 未记录到 A 键。从首笔 `StopMove` 起 0.721 秒进入持续低速，1.264 秒确认停稳，至进入持续低速的机身水平净位移为 2.38 毫米。真实发令进程已退出。电量不足后暂停测试，0.5 米/秒、4 秒未下发。充电后继续测量行走中由 A 键触发的停稳时间、位移和发令进程退出时刻。[五轮实机测试记录](a2-stop-test-results-20261122.md)

## 地图目标点验证

从闭环候选数据库的 357 个关键帧导出 0.20 米分辨率的二维栅格。使用本轮离线净空参数，在同一通道的两个录包位置间规划出约 1.75 米路径。原停稳起点因净空不足被拒绝，未知目标和不连通区段也被拒绝。ROS 2 只读探针已通过合成地图与里程计的正常、缺 TF 和过期用例。当前证据支持本机地图点选和静态规划。现场尺度、外廓、在线定位、指令桥接、控制权和停车仍待验证。[目标点验证流程](a2-goal-validation.md)
