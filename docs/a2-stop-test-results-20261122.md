# A2 停车实机记录（2026-11-21 至 11-22）

静止时按 A 已验证整条指令链。PC2 收到按键后，底盘接受了停车请求，模拟自主进程退出，停车锁存生效。行走试验中，现场看到 A2 迈步的一轮由速度保护先触发。**行走中按 A 到停稳的时间、距离，以及由 A 键终止真实发令进程，仍待实测。**

试验在 A2 的 PC2 上进行，环境为 Ubuntu 22.04.4、x86_64，宇树 A2 sport API 版本为 `1.0.0.1`，原厂速度档为 `0`。下表的速度是 `Move` 的前进请求值。RPC 返回码 0 表示底盘接受请求，是否迈步另由现场观察和机身里程计核对。

## 迈步后速度保护的停车测量

本轮保留了 0.10 米/秒的实测平面速度上限、5 厘米累计行程上限，以及检测到起步后 1 秒的发令时限。速度保护首先触发。发送者、独立监督和停车守护先后发出停车请求。以下数值均以 **首笔 `StopMove` 开始调用** 为零点，使用同一台 PC2 的单调时钟。

| 观测 | 实测值 |
| --- | --- |
| 底盘返回首个成功回执 | 发停后 0.51 毫秒 |
| 机身平面速度反馈峰值 | 0.219 米/秒，出现在发停后约 21 毫秒 |
| 机身与 IMU 进入随后持续的低速区间 | 发停后 0.721 秒 |
| 确认连续低速已保持至少 0.5 秒 | 发停后 1.264 秒 |
| 发停位置到进入持续低速位置的水平净位移 | 2.38 毫米 |
| 同一时段内距发停位置的最大水平偏移 | 7.09 毫米 |
| 同一时段内按采样点累加的水平轨迹长度 | 23.89 毫米 |

位置取自底盘机身里程计。净位移取起终点间距，最大偏移取轨迹上距起点最远的一点，折线长度累加每对相邻采样点的间距。停稳判定使用连续的机身速度、角速度、IMU 姿态和位置变化。静止 A 键试验的计时从 PC2 的遥控回调开始，实体按键到 PC2 收帧的无线传输耗时未知。

## 充电后的续测点

最后一次收尾时，真实发令进程已退出、控制组已清空，临时发令配置已撤下，停车守护保持锁存。随后因电量不足停测，提出的 **0.5 米/秒、4 秒未下发**。

充电后由现场重新确认站稳、控制区净空及独立急停，再复核 PC2 锁存和发令进程状态。下一轮由现场在迈步后按 A，同步记录 PC2 收到的按键上升沿、首笔停车请求及回执、机身持续停稳的时间与水平位移，以及原发令进程的退出时刻。若其他保护先触发，记录其原因和先后顺序。底盘在 PC2 停发或失联后的自行停车仍需另行验证。
